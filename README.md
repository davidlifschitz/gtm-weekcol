# WeekCol

Drop an ICS or paste dates. See weekday plus Sunday-start vs Monday-start columns. Nothing is uploaded.

Ask this answers: [the first day of the week being Sunday (US) and Monday (Europe) screws me up constantly](https://news.ycombinator.com/item?id=49372909)

- No account
- No upload
- Cap: 400 lines or 8 MB ICS
- US column 1 is Sunday. ISO column 1 is Monday.
- Flags meetings that sit in different columns on the two layouts

## Local

Open `index.html` in a browser, or:

```bash
python3 -m http.server 4173
```

This does not sync a calendar. It only labels dates.
